# Supported reference types

- Journal articles
- Books
- Book sections or chapters
- Conference papers
- Theses (PhD, Master's)
- Webpages
- Reports
- Preprints

## Notes

Zotero does not allow a DOI field for all item types. If a DOI cannot be set, the add-on stores it as `DOI:<doi>` in the item `Extra` field.
